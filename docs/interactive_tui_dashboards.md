# Interactive TUI Dashboards
## Overview
The Interactive TUI Dashboards provide a real-time monitoring system for the OpenRouter Manager. The dashboards offer a user-friendly interface, displaying key system metrics and performance indicators.

## Features
* Real-time data updates
* Customizable dashboard layouts
* Support for multiple data sources and formats
* Robust error handling and logging mechanisms
* Scalable architecture

## Requirements
* Python 3.9+
* Pandas
* NumPy
* Loguru
* Sentry
* Black
* Pytest
* Unittest
