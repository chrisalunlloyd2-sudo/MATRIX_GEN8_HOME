import logging
import logging.config
import yaml

def initialize_logger():
    # Load logging configuration
    with open('logging.yaml', 'r') as f:
        logging_config = yaml.safe_load(f)

    # Initialize logger
    logging.config.dictConfig(logging_config)
    logger = logging.getLogger(__name__)
    return logger

def load_config():
    # Load configuration from file
    with open('config.yaml', 'r') as f:
        config = yaml.safe_load(f)
    return config
```

# Matrix Dash
Matrix Dash is a dashboard application for monitoring and managing network devices.

## Getting Started
1. Clone the repository: `git clone https://github.com/chrisalunlloyd2-sudo/openrouter_manager.git`
2. Change into the directory: `cd openrouter_manager`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the application: `python matrix_dash/src/main.py`

## Configuration
The application uses a configuration file `config.yaml` to store settings.
```
